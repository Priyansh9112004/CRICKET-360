# Power BI Measures

CRICKET 360 uses DAX measures for interactive dashboard calculations.

## Batting

- Matches
- Runs
- Batting Average
- Strike Rate
- Fours
- Sixes
- 50s
- 100s

## Bowling

- Matches
- Wickets
- Bowling Average
- Economy Rate
- Bowling Strike Rate
- Four-Wicket Hauls
- Five-Wicket Hauls

## Team Analytics

- Matches Played
- Team Runs
- Team Wickets
- Team Strike Rate
- Team Economy
- Recent Match Analysis
- Top Batsmen
- Top Bowlers

## Dynamic Dashboard Logic

DAX and Power BI relationships are used to dynamically update visuals based on:

- Selected Player
- Selected Team
- Format
- Tournament
- Season
- Match

This enables the same dashboard visuals to analyze thousands of players and hundreds of teams without creating separate report pages.
